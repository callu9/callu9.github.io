문제
검색·목록·상세에서 같은 지원자 상태를 보여주면서, 저장 실패도 처리해야 했습니다.
담당 업무
지원자 검색·필터·상세 UI와 단계 변경, 실패 복원 및 중복 요청 방지를 구현했습니다.
핵심 결정
목록 전체를 되돌리면 다른 변경까지 사라질 수 있어, 저장에 실패한 지원자만 이전 단계로 복원했습니다.
  • React
  • TypeScript
  • TanStack Query
  • MSW
구현 자세히 보기

목록과 상세의 상태 기준을 하나로

지원자 정보를 화면마다 복사하지 않고 TanStack Query 캐시를 공통 기준으로 사용했습니다. 검색·필터·상세가 같은 지원자 상태를 보도록 구성했습니다.

즉시 반영하되, 실패 복원은 지원자별로

단계 변경은 낙관적으로 화면에 반영합니다. 예를 들어 A의 변경이 실패하고 B의 변경이 성공했다면, A만 복원하고 B는 유지하도록 설계했습니다. 같은 지원자는 요청이 끝날 때까지 추가 변경을 막고, 다른 지원자의 변경은 별도로 처리합니다.

MSW·localStorage 기반 데모입니다. 위 A/B 상황은 설계 의도를 설명하는 예시이며, 실제 채용 운영이나 다중 사용자 동시 처리 검증을 의미하지 않습니다.
